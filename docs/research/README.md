# Research

Sauron studies isolation failures in agents that share infrastructure across
multiple people. These notes develop the test method, connect it to prior work,
and define the validation experiments.

| Read | Focus |
|---|---|
| [Boundary-testing design](boundary-testing.md) | Turn context mixing and wrong-recipient delivery into observable test failures |
| [Selected prior art](prior-art.md) | Compare the proposal with concrete channel tests, agent evaluations and simulation systems |
| [Validation plan](evidence-standards.md) | Test the checker with known faults and measure reproduction, reduction and added coverage |

The scope is context exposure and wrong-recipient delivery. Start with the design
for the full argument, or the prior-art comparison for its research foundations.
